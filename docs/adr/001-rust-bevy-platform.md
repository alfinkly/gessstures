# ADR-001: Выбор Rust и Bevy как основной платформы

**Статус:** Принято

## Контекст

Необходимо высокопроизводительное 3D-приложение с захватом жестов и возможностью расширения. Требуется нативный GUI без JavaScript.

## Решение

Использовать Rust + Bevy (рендеринг, ECS, окно, камера, плагины). Вся логика — в одном процессе.

## Последствия

- Высокая скорость, предсказуемая производительность.
- Нет необходимости в браузере, кросс-платформенность через Bevy.
- Все компоненты (AI, граф, ввод) — в едином цикле событий, что упрощает синхронизацию.
