# ADR-007: Единый формат событий графа

**Статус:** Принято

## Контекст

Данные от AI-пайплайна, источников данных и запросов должны преобразовываться в единый граф для визуализации.

## Решение

Все события (`GraphUpdate`, `GraphQuery`) оперируют `StableGraph<NodeData, EdgeData>` из `petgraph`. `NodeData` содержит `id`, `label`, `embedding` (опционально). `EdgeData` — вес.

## Последствия

- Независимость от AI-бэкенда.
- Возможность кеширования графа.
- Единый механизм обновления рендерера.
