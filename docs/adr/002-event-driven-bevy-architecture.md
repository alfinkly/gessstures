# ADR-002: Событийно-ориентированная архитектура на Bevy Events

**Статус:** Принято

## Контекст

Необходима слабая связность между источниками данных, AI-конвейером, рендерером и управлением.

## Решение

Использовать Bevy Event для всех межкомпонентных сообщений (`NewContent`, `GraphUpdate`, `GraphChanged`, `CameraCommand`, `GraphQuery`). Каждый плагин публикует/подписывается на события.

## Последствия

- Модули не знают друг о друге, легко заменять/добавлять новые.
- Поток данных прозрачен, удобно отлаживать.
- Небольшой оверхед на копирование событий, допустимый для наших частот.
