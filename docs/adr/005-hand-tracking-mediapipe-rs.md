# ADR-005: Hand Tracking через mediapipe-rs

**Статус:** Принято

## Контекст

Необходимо отслеживание одной руки без JavaScript.

## Решение

Использовать официальные Rust-биндинги MediaPipe (`mediapipe-rs`). Интегрировать как Bevy-плагин, отправляющий `CameraCommand` по жестам (pinch-zoom, pan, orbit).

## Последствия

- Полный нативный стек.
- Придётся самостоятельно реализовать детекцию жестов (pinch, open palm) на основе ландмарок.
- Производительность достаточная (отдельный поток или асинхронно).
