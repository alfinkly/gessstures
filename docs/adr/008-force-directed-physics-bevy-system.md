# ADR-008: Физическая симуляция как система Bevy

**Статус:** Принято

## Контекст

Узлы графа должны динамически раскладываться в 3D.

## Решение

Реализовать force-directed алгоритм в системе Bevy, обновляющей `Transform` узлов. Силы: отталкивание, притяжение связей, затухание. Использовать ресурс `GraphLayoutState`.

## Последствия

- Выполняется каждый кадр, 60 fps.
- Простота и полный контроль.
- В будущем можно заменить на более продвинутую раскладку.
