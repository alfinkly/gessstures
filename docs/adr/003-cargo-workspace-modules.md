# ADR-003: Модульная организация через Cargo Workspace

**Статус:** Принято

## Контекст

Проект включает разнородные части (граф, AI, ввод, данные). Логическая изоляция упрощает тестирование и расширение.

## Решение

Разделить на 5 крейтов:

| Крейт         | Назначение                                                     |
|---------------|----------------------------------------------------------------|
| `graph-core`  | Граф, физика, события (`GraphUpdate`, `GraphChanged`, `CameraCommand`, `GraphQuery`) |
| `ai-pipeline` | Трейты и HTTP-реализация                                       |
| `data-sources`| Трейт `DataSource` + Markdown                                  |
| `input-sources`| Трейт `InputSource` + Hand + TextQuery                        |
| `app`         | Bevy-приложение, CLI, сборка плагинов                          |

## Последствия

- Чёткие границы ответственности.
- Крейт `graph-core` содержит все общие структуры и события, остальные от него зависят.
- CI может собирать и тестировать крейты независимо.
