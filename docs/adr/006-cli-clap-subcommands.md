# ADR-006: CLI на основе clap с подкомандами

**Статус:** Принято

## Контекст

Приложение должно иметь гибкие режимы запуска: десктопный рендер, веб-сервер, текстовый запрос, голосовое управление.

## Решение

Использовать `clap` (derive) с перечислением `Commands` (`desktop`, `web`, `query`, `voice`). В `main.rs` парсим и конфигурируем Bevy-плагины в зависимости от команды.

## Последствия

- Единый бинарник, множество режимов.
- Удобная автогенерация справки.
- Команды могут иметь свои аргументы (папка, порт, промпт и т.д.).
