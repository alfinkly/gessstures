ROOT CAUSE:
tract-tflite 0.22.1 does NOT handle the TFLite DEQUANTIZE operator (builtin_code=6).
The MediaPipe full models store weights in float16 format and use DEQUANTIZE ops
to convert f16→f32 during inference. tract-tflite simply doesn't register a handler
for DEQUANTIZE in its op registry (registry.rs).

tract-core HAS a Cast operator that could handle f16→f32 conversion, but tract-tflite
does not wire it up for DEQUANTIZE.

Neither tract-tflite 0.22.1 nor 0.23.0-dev.5 handles DEQUANTIZE.

FALLBACK OPTIONS:
1. Convert models: Strip DEQUANTIZE ops and convert f16→f32 in the TFLite flatbuffer
2. Python sidecar: Run official MediaPipe via subprocess (most reliable)
3. ONNX Runtime (ort crate): Convert models to ONNX, use ort
4. Implement DEQUANTIZE in tract-tflite: ~20 lines of Rust code, but requires fork
